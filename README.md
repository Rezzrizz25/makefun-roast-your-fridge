# Roast Your Fridge — One Line, One Laugh

A single-line roast of my fridge for the [One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) bounty on make.fun. One line, under 200 characters, judged blind by a comedy-club judge against other entries.

> "My fridge hums all night like it's guarding gold, but open the door and the treasure is one expired yogurt and a pickle that outlived my last three diets."

## Run it

```sh
node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), enforcing the gate: a single non-blank line of 1–199 characters.
